# The demo's excerpt

`train.bin.gz` and `dev.bin` are excerpts of TinyStories V2 (Eldan and Li, 2023), with story separators turned into one NUL byte. The dataset is under the Community Data License Agreement, Sharing, version 1.0 (https://cdla.dev/sharing-1-0/), and so are these excerpts. Source: https://huggingface.co/datasets/roneneldan/TinyStories
