A speedrun for training a small language model, with a meter where the clock would be.

Every tensor operation costs ticks, priced from its shape alone. An entry gets 40 billion of them, so a laptop and a server run the same program to the same reading and the same score. Hardware only buys finishing sooner.

What a tick buys

  
A tick is about a nanosecond of one laptop core, priced so that an entry can't get cheap work by picking the op the list underprices. Change the budget and the recipes keep their order at the top. The tuned recipes here are not retuned at other budgets, so a line that bends the wrong way is a recipe outgrowing its settings.
